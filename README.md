# 😋Meal buddy

## 📌 Project Overview
Meal buddy is a simple meal scheduling assistant that helps user create a meal schedule based on their needs.The user can provide the number of the schedule, the ingredients they currently have and any food allergies they want to avoid.

based on the user's requirements, Meal buddy generates a suitable meals schedule and takes the provided allergies into consideration while creating it user can provide their requirements.   

## 🎯 Problem Statement
- Planning meals for several days can be difficult when users have limited ingredients or specific food allergies.
- People may spend time deciding what to cook each day and may accidentally choose meals that contain ingredients they need to avoid.

There is a need for a simple assistant that can consider the user's available ingredients, allergies, and required number of days and help create a suitable meal schedule based on these requirements.

## 🛠️ Technology Stack
- Python
- ollama
- Streamlit
